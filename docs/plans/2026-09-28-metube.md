**Goal:** A tailnet-only web UI for `yt-dlp` on a bounded staging disk, with downloads deleted when their job is cleared.

**Architecture:** One container on `docker-host` joining the external `proxy` network, with `URL_PREFIX=/metube` so Caddy can route it at a subpath. Downloads live on a dedicated 25 GB disk at `/srv/metube`. Never public.

**Tech Stack:** Docker Compose, `ghcr.io/alexta69/metube:2026.09.28`, Caddy (existing).

**Spec:** `docs/specs/2026-09-28-metube-design.md`

## Global Constraints

- **Tailnet-only.** Never funnel it — a public downloader is an SSRF/abuse magnet.
- **No host port**: Caddy reaches it on `proxy` (`metube:8081`).
- **`URL_PREFIX=/metube`** and **no prefix stripping** in Caddy (the app applies it).
- **`CLEAR_COMPLETED_AFTER=0`** — never auto-clear, or delete-on-trashcan destroys files before collection.
- **Keep the SSRF guard on** (`ALLOW_PRIVATE_ADDRESSES=false`) and **overrides off**.
- Downloads on `/srv/metube` — **never** the root disk. Image pinned.

## Review Focus

- **The subpath really works** — page **and an asset under the prefix** (pinned by Task 2 Steps 3–4).
- **The trailing slash** — `/metube` must redirect to `/metube/` (Task 2 Step 5).
- **Delete-on-collect is safe** — `CLEAR_COMPLETED_AFTER=0` (Task 1 Step 1).
- **Nothing else disturbed** — Task 2 Step 6.

## Task 1: Disk + stack

- [ ] **Step 1** — `qm set 100 --scsi4 local-lvm:25,…`; identify the new device by
  **size and blankness** (names reorder on reboot — never trust `/dev/sdX`); mkfs
  ext4 label `metube`; fstab by UUID; mount `/srv/metube`; `mkdir …/downloads`
  **after** mounting (creating it before hides it under the mount); chown `1000:1000`.
- [ ] **Step 2** — `stacks/metube/compose.yaml` with `URL_PREFIX=/metube`,
  `DELETE_FILE_ON_TRASHCAN=true`, `CLEAR_COMPLETED_AFTER="0"`,
  `MAX_CONCURRENT_DOWNLOADS=3`, `ALLOW_PRIVATE_ADDRESSES=false`,
  `ALLOW_YTDL_OPTIONS_OVERRIDES=false`, `PUID/PGID=1000`,
  volume `/srv/metube/downloads:/downloads`, network `proxy`.
